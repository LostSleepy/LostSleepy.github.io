## 📖 About the project

A hybrid platform that combines a **fan-made encyclopedia of the *Jujutsu Kaisen* universe** with a **modern personal portfolio**, built following the latest UI/UX trends (Glassmorphism, Bento Grid, micro-interactions and fluid animations).

| ⛩️ JJK Wiki | ⚡ Sleepy's Portfolio |
| :---: | :---: |
| Fan encyclopedia of Gege Akutami's work | Professional profile of **Pedro Barrante (Sleepy)** |
| Character sheets, cursed techniques and multimedia gallery | Career path, passions, social networks and contact |
| Dark aesthetic inspired by the anime | Futuristic aesthetic with energy orbs and glass cards |

## ⛩️ Jujutsu Kaisen Fan Wiki

A comprehensive knowledge base about Gege Akutami's universe, focused on user experience and visual fidelity to the series' aesthetics.

### ✨ Features

- **📊 Universe stats:** Animated counters with canon figures — 271 manga chapters, 59 anime episodes, 16 domain expansion users and over 100 named characters.
- **👤 Character sheets:** Detailed pages for special-grade characters such as **Satoru Gojo**, **Megumi Fushiguro**, **Nobara Kugisaki** and **Itadori Yūji**.
- **🌀 Cursed techniques:** A dedicated section for Domain Expansions (Unlimited Void, Malevolent Shrine, Chimera Shadow Garden, Self-Embodiment of Perfection).
- **🖼️ Multimedia gallery:** *Lightbox* viewer with optimized GIFs and artwork of Gojo, Itadori, Sukuna, Maki, Yuta, Nanami and more.
- **✨ Premium details:** Giant kanji with parallax effect, floating particles, animated circular seals and scroll-reveal transitions.

Located in the `/Sleepy` directory, this section showcases the professional and personal profile of the author, **Pedro Barrante (Sleepy)**. It has been redesigned following current UI/UX trends.

### ✨ Features

- **🧩 Bento Grid:** A modern interface that organizes information into hierarchical visual blocks.
- **📚 Key sections:**
  - **Career path:** A narrative timeline of the professional evolution, from **IT Systems Technician (SMR)** to a **Higher Degree in Multi-platform Application Development (DAM)**.
  - **Passions:** Friends, a passion for Sevilla FC and creative direction inspired by Travis Scott.
  - **Social Hub:** A connectivity center with GitHub, LinkedIn, Twitch, YouTube, Spotify, Reddit, X and direct WhatsApp contact.

## 🚀 How to run

It's a **100% static site**: no installation or server required.

```bash
# Option 1: clone and open directly
git clone https://github.com/LostSleepy/LostSleepy.github.io.git
cd LostSleepy.github.io
start index.html      # Windows
# open index.html    # macOS
# xdg-open index.html # Linux

# Option 2: local server (optional, with Python)
python -m http.server 8080
# → open http://localhost:8080
```

### 🧭 Navigation

1. **Main Wiki:** run `index.html` in the root directory.
2. **Personal Portfolio:** access via the **"Creador"** link in the menu or by directly opening `Sleepy/index.html`.
3. **External portfolio:** a link to `lostsleepy.github.io/pagina-web-cv` is available from the contact page.
