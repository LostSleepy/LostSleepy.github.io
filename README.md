## 📖 Sobre el proyecto

Una plataforma híbrida que combina una **enciclopedia fan-made del universo de *Jujutsu Kaisen*** con un **portfolio personal moderno**, diseñado siguiendo las últimas tendencias en UI/UX (Glassmorphism, Bento Grid, micro-interacciones y animaciones fluidas).

| ⛩️ Wiki JJK | ⚡ Portfolio Sleepy |
| :---: | :---: |
| Enciclopedia fan de la obra de Gege Akutami | Perfil profesional de **Pedro Barrante (Sleepy)** |
| Fichas de personajes, técnicas y galería multimedia | Trayectoria, pasiones, redes sociales y contacto |
| Estética oscura inspirada en el anime | Estética futurista con orbes de energía y glass cards |

## ⛩️ Wiki Jujutsu Kaisen

Una base de conocimiento completa sobre el universo de Gege Akutami, centrada en la experiencia de usuario y en la fidelidad visual a la estética de la serie.

### ✨ Características

- **📊 Estadísticas del universo:** Contadores animados con cifras del canon — 271 capítulos del manga, 59 episodios del anime, 16 usuarios con expansión de dominio y más de 100 personajes con nombre.
- **👤 Fichas de personajes:** Páginas detalladas de personajes de grado especial como **Satoru Gojo**, **Megumi Fushiguro**, **Nobara Kugisaki** e **Itadori Yūji**.
- **🌀 Técnicas malditas:** Sección dedicada a las Expansiones de Dominio (Vacío Ilimitado, Santuario Malévolo, Jardín de las Sombras Quiméricas, Autoencarnación de la Perfección).
- **🖼️ Galería multimedia:** Visor *lightbox* con GIFs e ilustraciones optimizadas de Gojo, Itadori, Sukuna, Maki, Yuta, Nanami y más.
- **✨ Detalles premium:** Kanji gigante con efecto parallax, partículas flotantes, sellos circulares animados y *reveal on scroll*.

### 🗂️ Páginas de la wiki

## ⚡ Portfolio de Sleepy

Ubicado en el directorio `/Sleepy`, esta sección muestra el perfil profesional y personal del autor, **Pedro Barrante (Sleepy)**, rediseñado siguiendo las tendencias actuales de UI/UX.

### ✨ Características

- **🧩 Bento Grid:** Interfaz moderna que organiza la información en bloques visuales jerarquizados.
- **📚 Secciones clave:**
  - **Trayectoria:** Línea de tiempo narrativa de la evolución profesional, desde **Técnico en Sistemas Microinformáticos y Redes (SMR)** hasta el **Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**.
  - **Pasiones:** Amigos, pasión por el Sevilla FC y dirección creativa inspirada en Travis Scott.
  - **Social Hub:** Centro de conexión con GitHub, LinkedIn, Twitch, YouTube, Spotify, Reddit, X y contacto directo por WhatsApp.
- **📬 Formulario de contacto:** Totalmente funcional, integrado con **Formspree** para la captación de leads sin necesidad de un backend PHP.

### 🗂️ Páginas del portfolio

## 🚀 Cómo ejecutar

Es un sitio **100% estático**: no requiere instalación ni servidor.

```bash
# Opción 1: clonar y abrir directamente
git clone https://github.com/LostSleepy/LostSleepy.github.io.git
cd LostSleepy.github.io
start index.html      # Windows
# open index.html    # macOS
# xdg-open index.html # Linux

# Opción 2: servidor local (opcional, con Python)
python -m http.server 8080
# → abre http://localhost:8080
```

### 🧭 Navegación

1. **Wiki principal:** ejecuta `index.html` en la raíz.
2. **Portfolio personal:** accede desde el enlace **"Creador"** del menú o abriendo directamente `Sleepy/index.html`.
3. **Portfolio externo:** disponible un enlace a `lostsleepy.github.io/pagina-web-cv` desde la página de contacto.
